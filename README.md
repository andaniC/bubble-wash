# Bubble Wash

A 3D washing game for little ones, built with three.js.

**Play:** https://andanic.github.io/bubble-wash/

Rub the muddy toy to scrub it, spray the foam off, dry it with the towel, and watch it shine. Every level has three toys, a new scene and a new kind of mess (mud, sand, paint, jam, slime, chocolate). There are 12 hand-made levels, then new ones keep coming.

Run locally with any static server, e.g. `python3 -m http.server`.
