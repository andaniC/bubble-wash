# Splash Wash

A pixel-art power-washing game in the browser.

**Play:** https://andanic.github.io/bubble-wash/

24 jobs, from a muddy football and dinner plates to a driveway, a house, a school bus, a pirate ship and a rocket. Blast every pixel of mud, moss, grime, oil, gum, graffiti, bird poop and cobwebs off with the pressure washer; blow leaves away with the leaf blower; foam oil with the soap cannon; scrub plates with the sponge. Every finished part dings. Earn money, buy tools and pump upgrades, unlock bigger jobs.

Plain JavaScript, no build step. Run locally with any static server, e.g. `python3 -m http.server`.
